# Tarjeta Digital ANHETech ERP™

Tarjeta digital de **ANHETech ERP™**, con servicios de desarrollo web, aplicaciones, software a la medida, ERP y automatización.
Incluye contacto empresarial, perfil del CEO, botones para guardar el contacto completo y opciones para compartirlo por WhatsApp.

La tarjeta se organiza en una sola vista compacta: encabezado de marca, cinco servicios profesionales, llamada a la acción, contacto y redes, código QR y perfil del CEO. La identidad oficial se mantiene con el nombre **ANHETech ERP™**, el eslogan **Tecnología que impulsa tus ideas** y la paleta azul profundo con acentos turquesa.

## Cómo ver la tarjeta en el computador

1. Abre la carpeta `ANHETech-Tarjeta-Digital`.
2. Haz doble clic en `index.html`.
3. Se abrirá en el navegador. Los botones de teléfono, WhatsApp, correo y enlaces funcionan con conexión a internet.

> Para probar la descarga del contacto como en el sitio publicado, es mejor usar el enlace público.

## Cómo se publica

El sitio se publica automáticamente con **GitHub Pages** desde la rama `main`, carpeta raíz (`/`).
Cada vez que se sube un cambio a `main`, GitHub actualiza la página en unos minutos.

## Compartir el contacto

El botón **Compartir contacto** ofrece cuatro alternativas:

- Descargar el archivo `.vcf` completo.
- Abrir un mensaje de WhatsApp empresarial con los datos.
- Abrir un mensaje de WhatsApp personal con los datos.
- Copiar el texto de contacto al portapapeles.

WhatsApp abre el mensaje para revisarlo y enviarlo; guardar el contacto depende del teléfono o de la aplicación de contactos de cada persona.
